# F1RST MOTORS — 3D Concept Site

Тёмный сайт автодилера с интерактивной 3D-подачей: параллакс в hero-блоке,
3D-объекты машин на чистом CSS (без внешних изображений/библиотек) и
tilt-эффект карточек в каталоге.

## Структура

```
first-motors/
├── index.html      — главная (hero + блок "sell & rent")
├── cars.html        — каталог машин с 3D tilt-карточками и поиском
├── css/style.css    — все стили и 3D-конструкция машин
├── js/script.js     — параллакс, tilt, поиск, переключение цвета
└── README.md
```

## Локальный запуск

Никакой сборки не требуется — это чистые HTML/CSS/JS.

```bash
# любой локальный сервер, например:
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Можно просто открыть `index.html` двойным кликом, но локальный сервер
рекомендуется, чтобы шрифты и относительные пути работали одинаково с
продакшеном.

## Про изображения машин

В оригинальном макете использовались фото конкретных автомобилей
(Mercedes S-Class, BMW M4/M5/M8, Porsche 911). Из-за авторских прав на
пресс-фото производителей я не стал вставлять их напрямую — вместо этого
машины отрисованы как 3D-объекты на CSS (объём, блики, колёса, стёкла),
раскрашенные под каждую модель. Названия моделей оставлены как в макете
(текстовые подписи и кнопки не менялись).

Если у вас есть права на собственные фото машин — замените блоки
`.car3d` на `<img>` в `index.html` / `cars.html` и настройте `object-fit: cover`
в CSS; вся 3D/параллакс-логика в `script.js` продолжит работать поверх
обычных картинок (просто оберните `<img>` в те же `data-depth`-контейнеры).

## Загрузка на GitHub

```bash
cd first-motors
git init
git add .
git commit -m "Initial commit: F1RST MOTORS 3D concept site"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<название-репозитория>.git
git push -u origin main
```

## Бесплатный хостинг (GitHub Pages)

1. В репозитории откройте **Settings → Pages**.
2. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)**.
3. Сохраните — через минуту сайт будет доступен по адресу
   `https://<ваш-логин>.github.io/<название-репозитория>/`.
